# Tasks: Governed KPI Management

**Input**: `specs/001-kpi-management/{spec.md,plan.md,research.md,data-model.md,quickstart.md,contracts/}` and the repository constitution.

**Feature**: `001-kpi-management`
**Workflow**: remain on `main`; never create a branch whose name contains `codex`.
**Tests**: mandatory. Each behavior slice uses the public seam named in its task and follows RED -> minimal GREEN -> focused harness verification -> refactor while green.
**Verification**: `./harness.cmd` is the only verification interface. Until the harness has a narrower declared test profile, the focused verification command is `./harness.cmd test`; integration checkpoints also run `./harness.cmd lint` and `./harness.cmd check`.

## Task protocol

Every checklist item supplies its precondition (`Depends`), the public test seam (`Seam`), canonical verification (`Verify`), and observable review outcome (`Done`). A **RED** item adds one focused public-behavior test and proves it fails for the missing behavior; its immediately following **GREEN** item provides only the minimum production change needed to make that test pass. Do not mark an item complete until its stated command passes.
